# TomTroc

OpenClassrooms Project 6

## About

TomTroc is a book-sharing platform developed as part of the PHP Application Developer training programme at OpenClassrooms.

Users can browse the book catalogue, create an account, exchange messages, manage their books and update their profile.

## Features

- Browse the book catalogue and view book details.
- Create an account, log in and log out.
- Stay signed in using the Remember me option (30 days).
- Request a password reset by email using a temporary, single-use link.
- Manage a personal profile and books.
- Add, edit and delete books, including their pictures.
- Start conversations and exchange messages.
- Automatically refresh messages and unread-message counts.
- Responsive interface for desktop, tablet and mobile devices.

## Technologies

- PHP 8.1+
- MariaDB / MySQL and PDO
- HTML5, CSS3 and JavaScript
- Apache
- XAMPP
- MailDev for local email testing

The application follows the MVC architecture and uses a custom router and a front controller. It does not use any PHP framework, Twig, Doctrine or routing library.

## Requirements

- XAMPP (Apache, PHP and MariaDB/MySQL)
- Git (optional, for cloning the repository)
- Node.js and npm (required only for MailDev)

## Installation

1. Start XAMPP
   Open the XAMPP Control Panel and start Apache and MySQL.

2. Get the project
   Clone the repository into C:\xampp\htdocs:

   ```powershell
   cd C:\xampp\htdocs
   git clone https://github.com/Johan-Tnt/Ternant_Johan_TomTroc.git Ternant_Johan_Option_B_1_TomTroc_12_06_2026
   ```

Alternatively, download the repository as a ZIP archive and extract it into the XAMPP web directory. Make sure the extracted folder is named Ternant_Johan_Option_B_1_TomTroc_12_06_2026.

3. Create the database
   - Open phpMyAdmin.
   - Create a database named tomtroc.
   - Select the database and open the Import tab.
   - Import the SQL file located in the database/ directory: `schema.sql`. To use the sample accounts and books, import `tomtroc.sql` into an empty tomtroc database instead.
   - Check that the following tables have been created: users, books, conversations, messages, password_reset_tokens and remember_tokens.

**Note:** `schema.sql` contains the database structure only. The full database export, `tomtroc.sql`, is provided separately with the project deliverables. It includes the sample data. Import `tomtroc.sql` into an empty `tomtroc` database to use the sample accounts and books.

4. Configure the environment
   At the project root, copy .env.example to .env:

   ```powershell
   Copy-Item .env.example .env
   ```

Update the database settings and application URL to match your local installation:
DB_HOST=
DB_NAME=
DB_USER=
DB_PASSWORD=
APP_URL=http://localhost/Ternant_Johan_Option_B_1_TomTroc_12_06_2026/public
MAIL_FROM_ADDRESS=your-email@example.com

Adjust the database credentials if necessary. Keep the .env private and do not commit it to Git.

5. Configure MailDev for local email testing
   Install MailDev:

   ```powershell
   npm.cmd install -g maildev
   ```

   Start MailDev in a separate PowerShell terminal:

   ```powershell
   maildev.cmd
   ```

Keep the terminal open while testing the application.
Default MailDev settings:

- SMTP: localhost:1025
- Web interface: http://localhost:1080/

In C:\xampp\php\php.ini, check the [mail function] section and configure:
SMTP=localhost
smtp_port=1025
sendmail_from=tomtroc@example.com

Save the file and restart Apache.

Open http://localhost:1080/ to view emails generated by the application. MailDev captures emails locally and does not deliver them to real inboxes.

6. Open the application
   Visit:
   http://localhost/Ternant_Johan_Option_B_1_TomTroc_12_06_2026/public/

## Using the application

- Create an account or use an account from the imported sample data.
- Browse the catalogue and view book details.
- Add, edit or delete your books.
- Manage your profile.
- Start conversations and exchange messages.
- Test the Remember me option.
- Test password recovery using an email address registered in the database. Open MailDev and follow the reset link.

Password reset links expire after one hour and can only be used once.

## Development notes

This project is intended for educational purposes and local development. MailDev is used to test outgoing emails locally.

A production deployment requires a properly configured email service, secure environment variable management and suitable hosting.
